# Support

This repository is a public portfolio project and does not include a paid support contract or SLA.

## Questions and defects

Use GitHub Issues for:

- reproducible defects
- unclear setup or handoff documentation
- compatibility problems
- narrowly scoped enhancement requests

Include the Node.js version, operating system, exact command, expected behavior, and observed behavior when relevant.

## Security and data

Do not post API keys, credentials, private customer information, production database contents, or other secrets in a public issue.

Read `docs/SECURITY_AND_LIMITATIONS.md` before reporting behavior that may be an intentional product boundary.

## Scope

Support is limited to the code and documented demo workflow in this repository. Production hosting, external provider uptime, compliance, identity, tenancy, backups, and operational SLAs are outside the scope of this portfolio MVP.
